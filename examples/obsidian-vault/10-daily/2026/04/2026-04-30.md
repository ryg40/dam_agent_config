## Session opc-2026-04-30-002 — homelab-inference

- **summary**: Debugged vLLM tensor parallelism on mixed GPU setup (3090 + A6000)
- **tags**: #vllm #gpu #tensor-parallel #troubleshoot
- **confidence**: high

### Artifacts

```bash
# Working vLLM launch command
python -m vllm.entrypoints.openai.api_server \
  --model meta-llama/Llama-3.3-70B-Instruct \
  --tensor-parallel-size 2 \
  --gpu-memory-utilization 0.95 \
  --max-model-len 8192
```

### Decisions

- Use `CUDA_VISIBLE_DEVICES=0,1` to control GPU ordering
- Set `--gpu-memory-utilization 0.95` to maximize VRAM usage

### Learnings

- vLLM requires GPUs with same compute capability for tensor parallelism
- Mixed memory sizes work but limit model size to smallest GPU
